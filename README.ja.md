# mirne

Sony CECH-ZD1 J（PlayStation 用の地上デジタルチューナー）を Mac につないで、
地上デジタル放送を見るための macOS アプリです。

- チューナーの制御は [coax](https://github.com/Till0196/coax) の `coaxd` に任せます
- 映像と音声は macOS 標準のフレームワーク（VideoToolbox・AudioToolbox・Metal）で再生します

## 限定受信（CAS）について

**mirne は限定受信方式（B-CAS）の処理を含みません。** 地上デジタル放送の映像と音声は
スクランブルされているため、mirne だけでは視聴できません。

mirne が行うのは、設定で指定された外部のコマンド（標準入力の TS を受け取り、標準出力へ
TS を返すもの）を起動してつなぐことだけです。そのコマンドの入手と利用が、カードの
使用許諾契約や法令に照らして許されるかは、利用する人自身が判断してください。
このリポジトリでは、そのコマンドの入手先や設定例を案内しません。

mirne・coaxd・外部フィルタのつながりは次のとおりです。

```text
Sony CECH-ZD1 J
 │  USB
 ▼
coaxd（mirne に同梱。別のプロセスで動く）
 │  Unix ソケット（スクランブルされた TS）
 ▼
mirne
 ├─ 外部フィルタを起動する（設定で指定したコマンド。使う人が用意する）
 │   ├─ 受信した TS を標準入力へ渡し、標準出力から TS を受け取る
 │   └─ 設定でオンのとき：coax pcsc を起動し、そのソケットのパスを
 │      環境変数 PCSCLITE_CSOCK_NAME で渡す
 ▼
映像・音声・字幕・番組表
```

## できること

- **視聴**：チャンネルスキャンで見つけた局を、サイドバー・数字キー・↑↓ で選ぶ。同じ物理チャンネルのサブチャンネルへの切り替えは、選局し直さずに行う
- **ウィンドウ**：16:9 を保ったまま大きさを変えられる。全画面・常に最前面。位置と大きさ（どの画面か）とサイドバーの開閉を覚え、次に開いたときに戻す
- **字幕**：放送の指定どおりの色・位置・大きさで、映像に重ねて出す
- **音声**：二重音声（主・副・主＋副）と、複数の音声（副音声・解説放送など）を選べる。ステレオと 5.1ch に対応
- **番組表**：局を横・時間を縦に並べた番組表。番組を押すとその局を選局し、マウスを置くと番組の内容を吹き出しで出す。時刻の列は横に送っても左に残る。今日の朝 4 時から、集めた番組の最後の日までを日付をまたいで続けて送れる（朝 4 時の境目は太い線で示す）。番組の欄はジャンルの色で示す（左端の帯・背景。示し方と色、ジャンルごとに色を付けるかは設定の「番組表」で変えられる）。別のウィンドウでも、視聴ウィンドウに重ねても出せる。別のウィンドウの位置と大きさは次に開いたときに戻す
- **番組表の巡回**：視聴ウィンドウを閉じている間と、番組表を重ねて出している間に、局を順に受信して番組表を集める
- **起動したとき**：前回見ていた局を選局する（設定で切れる）
- **チャンネルの編集**：局ごとに、隠す・並べ替える・名前を変える
- **その他**：視聴中はディスプレイを眠らせない。チューナーの抜き差しやスリープからの復帰では、見ていた局に戻る

## 動作環境

- Apple Silicon の Mac
- macOS 15 以上
- Sony CECH-ZD1 J

## ビルド

必要なもの: Xcode、[XcodeGen](https://github.com/yonaskolb/XcodeGen)、Go（coax のビルド用）

```bash
scripts/fetch-coax.sh   # coax を取得して coaxd と coax をビルドする
./build.sh              # Debug でビルドする（Release は ./build.sh release）
./build.sh test         # 単体試験を流す
```

ビルドすると、取得した `coaxd`・`coax` が `mirne.app/Contents/Helpers/` に入ります。
成果物は `build/symroot/<構成>/mirne.app` です。

署名は既定でアドホック署名です。自分の証明書で署名するときは
`Config/Local.xcconfig.example` を `Config/Local.xcconfig` として複製し、書き換えてください。
`Config/Local.xcconfig` に Developer ID の証明書と notarytool のプロファイル名を書けば、
`scripts/notarize.sh` で公証済みの `build/notarized/mirne.app` を作れます。

再生系の計測用の画面（環境変数 `MIRNE_LAB_FILE` などを付けて起動したときだけ開く）で使う試験用の TS は、次で生成できます（ffmpeg が必要）。

```bash
scripts/make-fixtures.sh   # build/fixtures/ に検証用の TS を作る
```

## 使い方

1. チューナーをつないで mirne を起動し、「チャンネル」メニューの「チャンネルスキャン…」で局を探します
2. 設定（⌘,）の「外部フィルタ」に、受信した TS を通すコマンドを指定します
   - コマンドは、標準入力から TS を読み、標準出力へ TS を書くものにしてください
   - **標準入力が終わったら（EOF）、終了するものにしてください。** mirne は選局し直すたびにコマンドを起動し直します
   - 「coax pcsc のソケットを渡す」を入れると、`coax pcsc` を起動し、そのソケットのパスを環境変数 `PCSCLITE_CSOCK_NAME` で渡します
3. サイドバーで局を選びます

番組表の巡回は、外部フィルタを通さずに受信します（番組情報はスクランブルされていないため）。
coaxd へは視聴より低い優先度で頼むので、ほかの視聴が始まればチューナーを譲ります。

アプリのメニューと設定は日本語です。

### 外部フィルタの扱い

上の 2. に加えて、mirne は外部フィルタを次のように扱います。

- **起動**：コマンドは `/bin/sh -c` で実行します。環境変数は、mirne の環境に設定した分を上書きして足します。GUI アプリの `PATH` は短いので、コマンドは絶対パスで書くのが確実です。渡すファイル記述子は、標準入力・標準出力・標準エラーの 3 つだけです
- **止め方**：標準入力を閉じます。1 秒待っても終わらなければプロセスグループへ SIGTERM を送り、さらに 1 秒待って SIGKILL を送ります（コマンドが起動した子プロセスも止まります）
- **出力が途切れたとき**：標準出力に 5 秒何も来なければ、止まったとみなして選局し直します。mirne が止めていないのに標準出力が終わった（EOF）ときも同じです。受信が 30 秒続かずに途切れるのが 4 回続いたら、選局をやめて画面に知らせます
- **標準エラー**：最初の 4 KB を、途切れた理由として画面とログに出します。受信した局などが含まれることがあるので、ログを人に渡すときは気を付けてください

### キー

| キー | 動作 |
| --- | --- |
| 1〜9・0・-・^ | リモコンキー 1〜12 の局を選ぶ（0 が 10、- が 11、^ が 12） |
| ↑ / ↓ | 前 / 次の局 |
| G / Shift+G | 番組表 / 番組表を重ねて表示 |
| F | 全画面 |
| T | 常に最前面 |
| ⌘0 | ウィンドウを標準の大きさに戻す |
| C | 字幕 |
| I | 受信状態 |
| A | 音声を切り替える |
| M | ミュート |
| ⌘↑ / ⌘↓ | 音量 |

### データの置き場所

チャンネル一覧と番組表は `~/Library/Application Support/mirne/` に置きます
（`channels.json`・`epg.sqlite`）。設定はアプリの UserDefaults（`com.slack-kingdom.mirne`）です。
